# Workbook

`bridge_energy_sales_operations_crm_project.xlsx` contains:

- an executive dashboard;
- a formula-driven, 100-point lead-scoring model for 160 prospects;
- the top-30 high-priority campaign list;
- raw-data and deduplication audit tabs;
- editable rules and assumptions; and
- a Salesforce field map and import workflow.

Reported direct emissions are used as a transparent facility-scale proxy, not
as utility consumption, revenue, employee count, or projected account value.
